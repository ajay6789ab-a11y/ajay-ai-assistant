Ajay AI Assistant

A live, working demo of the app: this UI is the web mirror of the Flutter client and it talks to the real FastAPI brain running in this workspace — bilingual NLU, memory, planner and tools included.

  • Tap the mic to speak (Chrome/Edge). Speech-to-text and text-to-speech run in the browser, exactly like the phone's engines.
  • Sensitive actions (call / message) always raise a consent sheet first.
  • Weather, news, translation and the calculator hit real services.
  • History, memory and settings persist in SQLite via the API.
